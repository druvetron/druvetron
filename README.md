- Backend layer linking a React Native frontend to a RAGFlow pipeline; improved response accuracy **+80%** through prompt design
- Feedback intelligence system summarizing 100+ raw responses per module into prioritized, actionable issues

- Automated citation generator + FastAPI analytics dashboard for real-time monitoring and data export
