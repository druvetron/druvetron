- Migrated Supabase → self-hosted PostgreSQL with a custom async ORM; built deterministic scoring engines for student engagement tracking

**Track 02 · Guru Sikshan** — *MFE · FastAPI · RAG · PostgreSQL · Gemini* · Feb 2026

- Backend layer linking a React Native frontend to a RAGFlow pipeline; improved response accuracy **+80%** through prompt design
- Feedback intelligence system summarizing 100+ raw responses per module into prioritized, actionable issues
- Secure API gateway with session management, containerized with Docker

**Track 03 · RoadIQ** — *Python · YOLO11m · BoT-SORT · FastAPI · OpenCV · Shapely*

- Detection engines for four traffic violations — illegal parking, wrong-side driving, missing helmets, triple-riding
- Automated citation generator + FastAPI analytics dashboard for real-time monitoring and data export
